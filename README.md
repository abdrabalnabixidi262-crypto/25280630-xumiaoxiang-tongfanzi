# Tong Fan Zai Immersive Site

An immersive red game-CG web portfolio for **Tong Fan Zai - Quanzhou City IP And Cultural Creative Design**.

Public site: <https://abdrabalnabixidi262-crypto.github.io/25280630-xumiaoxiang-tongfanzi/>

## Run

```bash
pnpm install
pnpm dev
```

Local URL: <http://127.0.0.1:8765/>

## Build

```bash
pnpm build
pnpm preview
```

Preview URL: <http://127.0.0.1:8766/>

## Test

```bash
pnpm lint
pnpm test
pnpm test:e2e
pnpm verify
```

## Showreel

```text
/?showreel=1
/?showreel=1&debugTimeline=1
```

Showreel mode runs an approximately 30-second reference-style automatic presentation. The normal website remains manually navigable by top navigation, wheel, keyboard, touch swipe and the glowing lower-right controller.
